المعلومات القانونية

سياسة ملفات تعريف الارتباط

معلومات بشأن ملفات تعريف الارتباط والتقنيات المشابهة على موقع مركز GOLD.

الموقع الحالي

لا يستخدم الموقع العام الحالي عمدًا ملفات تعريف ارتباط إعلانية أو ملفات لتتبع السلوك. وقد تعالج الوظائف التقنية الأساسية أو خدمات الأطراف الثالثة المستخدمة في النماذج أو الاستضافة أو المحتوى المضمّن معلومات تقنية وفق طريقة عملها وسياساتها.

التحليلات أو الخدمات المستقبلية

إذا أضاف GOLD أدوات تحليل أو تقنيات تسويق أو ملفات تعريف ارتباط غير أساسية، فينبغي تحديث هذه السياسة وأي آلية موافقة مطلوبة قبل تفعيل تلك التقنيات أو عند تفعيلها.

إعدادات المتصفح

تتيح معظم المتصفحات للمستخدمين إدارة ملفات تعريف الارتباط أو حظرها من خلال الإعدادات، وقد يؤثر حظر بعض التقنيات في وظائف الموقع.

مؤسسة مصرية متعددة التخصصات بامتداد دولي.
